# Targetologist Site

Bilingual (Russian/English) one-page website for Anna Melnikava, a Meta Ads specialist. It is static HTML/CSS/JS, with all served files in `public/`.

## Run and deploy

```
npx wrangler dev      # preview locally
npx wrangler deploy   # deploy to Cloudflare
```
